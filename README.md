Virtual Lab ini merupakan media pembelajaran interaktif berbasis web untuk materi Berpikir Komputasional dasar, meliputi input, output, tipe data, dan percabangan di Python.

Cara menggunakan:

1. Clone atau download repository.
2. Buka folder repository.
3. Buka file index.html menggunakan browser.

Alternatifnya, buka folder repository menggunakan Visual Studio Code dan jalankan index.html dengan Live Server.
